## Other platforms

From the same committed files, with PoWerRuSt 0.3.0 and cargo-pwrs 0.3.0 from crates.io, Rust 1.98.1 and Pester 6.2.0. The AlmaLinux container and the FreeBSD machine built the module themselves with `cargo build --release`, `cargo clippy --release --all-targets -- -D warnings` and `cargo pwrs test --release`, all clean. The Ubuntu machine ran the suite against the AlmaLinux build, the Windows 10 machine against the Windows 11 build, and the Windows Server 2019 machine against the package, installed from a local repository. The Pester tests a platform skips are the ones for other systems, 2 in each host on Windows and 4 elsewhere, which [How To Run The Tests](How-To-Run-The-Tests.md) names, and the Windows builds run one unit test more, the one that reads the Windows store.
